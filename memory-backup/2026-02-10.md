## CMS Component Pattern
Standard pattern established:
1. Create hook in `src/hooks/` or `src/components/[feature]/use[Feature].ts`
2. Create component in `src/components/[feature]/[Feature]Management.tsx`
3. Use Tailwind CSS + Lucide icons
4. Connect to Supabase via `src/lib/supabase.ts`

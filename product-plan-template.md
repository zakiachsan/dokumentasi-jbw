# Product Plan Template

Template standar untuk membuat dokumen product plan. Gunakan struktur ini untuk setiap project baru.

---

## Struktur Template

### 1. Header
```
# Product Plan: [Nama Project]

**Author:** [Nama]  
**Date:** [YYYY-MM-DD]

---
```

### 2. Latar Belakang & Goals

**Konten:**
- Jelaskan masalah saat ini (sistem lama, pain points)
- List goals sistem baru dalam numbered list (1-5 goals)

**Format:**
- Paragraph untuk latar belakang
- Numbered list untuk goals

### 3. Data/Context

**Konten:**
- Data yang relevan (customer, user, stakeholder)
- Tabel jika ada banyak data

**Format:**
- Table dengan 3 kolom (minimal)
- Atau bullet list jika data sederhana

### 4. Fitur-Fitur Sistem

**Struktur per fitur:**
```
### 4.X [Nomor Fitur]: [Nama Fitur]

#### [Sub-judul Fitur]
[Deskripsi singkat]

- Bullet list untuk detail fitur
- Minimal 3-5 poin

> **Benefit:** [Satu kalimat benefit utama]
```

**Format:**
- H3 untuk nama fitur
- H4 untuk sub-judul
- Bullet list untuk detail
- Callout box (quote/blockquote) untuk benefit

### 5. Tahap Pengembangan

**Struktur:**
- Gunakan toggle/accordion untuk setiap tahap
- Tahap 0: Persiapan
- Tahap 1: MVP (Dasar)
- Tahap 2+: Fitur tambahan

**Format:**
- Toggle sections (bisa expand/collapse)
- Bullet list di dalam toggle

### 6. Langkah Selanjutnya

**Konten:**
- 3 langkah konkret untuk memulai

**Format:**
- Numbered list

## Checklist Sebelum Finalisasi

- [ ] Semua goals jelas dan terukur
- [ ] Data/context lengkap
- [ ] Setiap fitur punya benefit yang jelas
- [ ] Tahap pengembangan realistis
- [ ] Langkah selanjutnya actionable

---

**Catatan:** Selalu gunakan format yang konsisten untuk kemudahan pembacaan dan review.
